
# 🛒 Sistema de Controle de Vendas em C#.NET e MySQL

Este é um sistema completo de **Controle de Vendas**, desenvolvido em **C#.NET** com banco de dados **MySQL**, aplicando **Programação Orientada a Objetos (POO)** e boas práticas de desenvolvimento.  

O objetivo do projeto é oferecer uma solução funcional para o **gerenciamento de clientes, fornecedores, funcionários, produtos e vendas**, com interface intuitiva em **Windows Forms**.

---

## 🚀 Funcionalidades

- **Cadastro, consulta, atualização e exclusão (CRUD):**
  - Clientes
  - Fornecedores
  - Funcionários
  - Produtos
- **Gestão de vendas:**
  - Registro de vendas
  - Itens de venda
  - Controle de pagamentos
- **Histórico e relatórios:**
  - Histórico de transações
  - Relatórios de desempenho
- **Integrações:**
  - Consulta automática de endereço via **APIs externas**
- **Interface gráfica:**
  - Desenvolvida em **Windows Forms**
  - Validações e tratamento de erros para melhor experiência do usuário

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C#.NET  
- **Banco de Dados:** MySQL  
- **Arquitetura:** POO, DAO (Data Access Object)  
- **Interface:** Windows Forms  
- **Integração:** APIs externas  

---

## 📂 Estrutura do Projeto

- **br.com.projeto.conexao** → Conexão com banco de dados  
- **br.com.projeto.dao** → Classes de acesso a dados (DAO)  
- **br.com.projeto.model** → Modelos das entidades (Cliente, Produto, Venda, etc.)  
- **br.com.projeto.view** → Telas do sistema (WinForms)  
- **Resources** → Ícones e imagens
